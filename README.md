# Lagerverwaltungs-System

## Beschreibung
- Webanwendung zur Verwaltung von Testanforderungen und -durchführungen.
- Ermöglicht das Erstellen von Anforderungen, das Erstellen von Testfällen und das Dokumentieren von Testergebnissen.
- Unterstützt die Arbeit von Requirements Engineers, Testmanagern und Testern in einem Web-Development-Team.

## Features
- **MUST**:
  - Anforderungen erstellen und zuweisen.
  - Testfälle erstellen und zuordnen.
  - Testergebnisse dokumentieren und nachverfolgen.

- **COULD**:
  - Übersicht über alle Testfälle und deren Status.

## Technologie Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Java, Spring Boot
- **Datenbank**: MySQL
- **Versionskontrolle**: GitHub
